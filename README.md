# Wenbo Zeng — Academic Homepage

Personal academic website for Wenbo Zeng, built from the [PRISM](https://github.com/xyjoey/PRISM) research portfolio template.

## Local development

Node.js 22 or later is required.

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The static export is generated in both `out/` and `docs/`. Pushing `main` triggers the GitHub Pages deployment workflow.

## Content

Site content is maintained in `content/` and `content_zh/`. Publications are stored as BibTeX in `publications.bib`.
